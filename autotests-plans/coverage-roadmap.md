# E2E Coverage Roadmap — last-episode

> Generated by GLOBAL_EXPLORE phase, 2026-05-27.

## Goal

Покрыть все пользовательские области приложения автоматизированными Playwright-тестами, начиная с критического пути и заканчивая расширенным функционалом.

## Области и приоритизация

### Tier 0 — Критический путь (без области приложение не работает)

| Область | Страница(ы) | Обоснование | P-уровень |
|---------|-------------|-------------|-----------|
| `auth` | `/login`, `/register` | Без аутентификации ни одна другая область недоступна. Login — единственный вход в систему. | P0 |

### Tier 1 — Основной флоу (>50% сценариев пользователя)

| Область | Страница(ы) | Обоснование | P-уровень |
|---------|-------------|-------------|-----------|
| `search` | `/search` | TMDB-поиск + добавление тайтла в библиотеку — основной способ пополнения коллекции. Используется при каждой новой записи. | P0 |
| `library` | `/library` (+ фильтры, сортировка) | Главная страница авторизованного пользователя. Отображает всю коллекцию, фильтры, удаление. | P0 |
| `media` | `/media/[id]` | Трекер эпизодов и сезонов — ключевая фича. Смена статуса, рейтинг, заметки, разметка эпизодов. | P0 |

### Tier 2 — Расширенный функционал

| Область | Страница(ы) | Обоснование | P-уровень |
|---------|-------------|-------------|-----------|
| `stats` | `/stats` | Read-only страница статистики. Простая, но важна для пользователя. | P1 |
| `community` | `/community` | Социальные функции: поиск пользователей, отправка/принятие запросов в друзья, список друзей. | P1 |
| `profile` | `/profile/[username]` | Просмотр профиля (своего и чужого), публичная библиотека. | P1 |

### Tier 3 — Сложный/нестабильный функционал

| Область | Страница(ы) | Обоснование | P-уровень |
|---------|-------------|-------------|-----------|
| `recommendations` | `/recommendations` | AI-рекомендации через Groq (SSE-стриминг) + обогащение через TMDB. Нестабильный из-за внешних зависимостей. Тестируется последним. | P1 |

## Очередь (порядок исполнения)

```
auth → search → library → media → stats → community → profile → recommendations
```

## MVP-критерии (минимум для релиза автотестов)

- [ ] Tier 0 покрыт полностью: auth, search, library, media
- [ ] Все P0-кейсы имеют статус COVERED
- [ ] 2 последовательных зелёных прогона для каждой области
- [ ] Нет CI-падений на `main`

## Риски

| Риск | Область | Митигация |
|------|---------|-----------|
| TMDB API rate-limit в тестах | search, media | Мокировать через `page.route()` для unit-flow, ограничить интеграционные тесты |
| Groq streaming flakiness | recommendations | Использовать `waitForSelector` с таймаутом, ставить retry=3 для этой области |
| Supabase RLS + auth state | все | `storageState` для переиспользования сессии; seed-данные перед запуском |
| Анимации/переходы (Framer Motion) | library, media | `waitForLoadState('networkidle')`, `locator.waitFor()` для завершения анимаций |
| Нестабильные локаторы (отсутствие aria) | library, community | LOCATOR_AUDIT фиксирует app-код при необходимости, добавляет aria-label |
